# MERA AI Mobile Web Starter

This is a phone-friendly web app prototype.

## Try it
Open `index.html` in a browser or upload the folder to a static HTTPS host such as GitHub Pages using your phone browser.

## Install on Android
Once hosted over HTTPS, open the URL in Chrome → menu (⋮) → **Add to Home screen** or **Install app**.

## Prototype limitations
- This is not an APK; it is a web app/PWA starter.
- AI replies are demo responses until an AI service is connected.
- Voice recognition depends on browser/device support.
- Camera button opens photo capture/file selection; it does not yet analyze images with AI.
- Alarm and app-launch actions vary by Android/browser. If the alarm link does not work, open the Clock app manually.
- “Hey Mera” always-on wake word, private memory, secure PIN, WhatsApp message sending, and full phone control are not implemented yet.
